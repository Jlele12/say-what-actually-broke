One line of software error copy for make.fun's "Say What Actually Broke" bounty: the brutal truth about the failure, told so a team would actually ship it in a dialog.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py   # writes /output/entry.txt
```

Deterministic: no clock, no randomness, no network. The output is the same on every run.
